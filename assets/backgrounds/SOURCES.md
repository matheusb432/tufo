## Notes

- NGA's IIIF server returns at most 4096 px on the long side for any size request, including `full/max`, `full/full`, and explicit widths.
- AIC's `full/max` and `full/full` URLs hit a Cloudflare challenge; an explicit `full/8600,` returns the native 8600x3958 image. Requests carry an `AIC-User-Agent` header.
- Micrio advertises `maxArea` 17550000, but `full/max` returned the native size for both Rijksmuseum objects.
- `dragon` stays under 2400 px. The only larger Commons copy of NG6294 is Sailko's framed gallery photo (3918x3102), licensed CC BY 3.0 rather than PD-Art.
- `cathedral`: the Met's own original is 1955x1541: <https://images.metmuseum.org/CRDImages/ep/original/DP164837.jpg>.
- `underworld` includes the frame and gallery wall. Unframed PD-Art alternatives on Commons: 3224x2127 <https://upload.wikimedia.org/wikipedia/commons/0/08/John_Martin_Le_Pandemonium_Louvre.JPG> and 2843x1895 <https://upload.wikimedia.org/wikipedia/commons/4/4c/Le_Pandemonium_-_John_Martin_-_Mus%C3%A9e_du_Louvre_Peintures_RF_2006_21.jpg>.
