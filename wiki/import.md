# Import from Kenku FM

Close Kenku FM and start the import from Settings. If Kenku FM's data isn't found, you'll be asked
for its folder. Nothing in Kenku FM changes and no audio is copied, so the files need to stay
where Kenku FM had them.

Playlists and soundboards come over with their titles, order, and supported settings, and ones
that match a folder stay in sync with it. When a collection already exists, choose **Keep** or
**Overwrite**.

The import keeps going if you close the dialog, and **Retry** picks up an interrupted one where it
stopped. Kenku FM's bot token is imported if you haven't saved one.

Web addresses, bookmarks, and streaming settings aren't imported.
